# Case

Case and plate designed in Onshape, 3D printed.

Rough dimensions: base 3–5 mm, walls ~12 mm, 14 mm switch cutouts on the 19.05 mm grid,
USB slot for the Pico's USB-C. Also needs a cutout/window for the OLED and clearance for
the encoder knob in the top-right. Exported to STL (mm) for printing and STEP for the repo.
